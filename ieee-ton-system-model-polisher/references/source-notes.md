# Source Notes Used to Build This Skill

These notes document the style influences used when the skill was created. They are not required for ordinary use.

## IEEE author guidance

IEEE Author Center guidance emphasizes that an article should communicate ideas clearly and that methodology should describe what was done and how it was done in a way that supports reproducibility. The IEEE Editorial Style Manual for Authors covers punctuation, capitalization, abbreviations, section headings, numbers, equations, footnotes, and related editorial conventions.

## Observed system-model patterns in networking papers

A strong networking system model often follows this progression: first set the time scale and modeling scope, then introduce network entities and services, then define decisions, then quantify energy/delay/throughput, and finally formulate the design problem. Open networking-paper examples show that system model sections are effective when they make assumptions explicit, keep operational timing clear, and use the last paragraph to motivate the algorithmic section.

Example public paper page consulted during construction:

- https://arxiv.org/abs/1801.05868

## Easy-to-read research writing influence

Research-writing guidance for technical articles emphasizes accessibility because readers have limited time and hard-to-read papers may be overlooked even when the technical contribution is strong. This skill therefore favors clarity, continuity, and complete explanation over unnecessary compression.
